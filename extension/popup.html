Quick Start

1. Run the Python backend: python automate.py signup-ext --email you@privatimail.com --password 'StrongPass123!'
2. Click Connect above (the Python server must be running first).
3. The extension will open the Notion signup page automatically.
4. Solve the hCaptcha when prompted — the extension captures the token.
5. The Python backend completes the rest (email code, login, onboarding).
